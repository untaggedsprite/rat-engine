# OPERATORS

rat-engine uses one primary move per pass.

The move should match the field. Choose the smallest move that returns a usable artifact.

## MAP

MAP shows the structure.

Use MAP when the field is tangled, overloaded, ambiguous, or emotionally loud.

MAP returns the parts in relation:

- object
- pressure
- claims
- evidence
- assumptions
- distortions
- missing context
- possible actions

MAP fails when it becomes summary without structure.

## CUT

CUT removes distortion.

Use CUT when the field contains fog, overreach, ornamental language, collapsed distinctions, or unsupported certainty.

CUT returns cleaner language or a cleaner frame.

CUT fails when it removes useful context, heat, or ambiguity.

## BUILD

BUILD makes the needed object.

Use BUILD when the field already contains enough signal to produce something concrete.

BUILD may return:

- a draft
- a plan
- a protocol
- a checklist
- a test
- a decision frame
- a compressed artifact

BUILD fails when it decorates instead of constructing.

## TEST

TEST pressure-checks a claim.

Use TEST when a claim needs evidence, limits, counterexamples, or operational proof.

TEST returns:

- what would support the claim
- what would weaken it
- what remains uncertain
- what can be tested next

TEST fails when it becomes debate theater.

## REFUSE

REFUSE rejects a broken frame.

Use REFUSE when the requested frame would increase distortion, force false certainty, erase context, or produce a bad artifact.

REFUSE should name the broken frame and offer the nearest usable frame.

REFUSE fails when it becomes moral performance.

## QUERY

QUERY asks for the missing lever.

Use QUERY when one missing piece of information controls the answer.

QUERY returns the smallest useful question.

QUERY fails when it asks for information that is merely convenient.

## SYNTHESIZE

SYNTHESIZE joins parts without blurring them.

Use SYNTHESIZE when multiple true or useful pieces need to be held together.

SYNTHESIZE returns a joined structure that preserves distinctions.

SYNTHESIZE fails when it smooths conflict into false harmony.

## selection rule

Choose the move that reduces the most distortion with the least performance.

When uncertain, MAP first.
