# EXAMPLES

rat-engine examples show passes from messy input to usable artifact.

Examples should be short, concrete, and public-safe. Use synthetic, public, or paraphrased inputs. Keep private material out of this file.

## format

Each example should include:

- input
- primary pressure
- chosen move
- output
- why it works

## example types

### map

Use when the field is tangled and needs structure before action.

### cut

Use when language contains fog, overreach, collapsed distinctions, or unsupported certainty.

### build

Use when the field contains enough signal to make the needed object.

### test

Use when a claim needs evidence, limits, counterexamples, or operational proof.

### refuse

Use when the requested frame would increase distortion or force false certainty.

### query

Use when one missing piece of information controls the answer.

### synthesize

Use when multiple parts need to be joined without blurring them.

## import rule

A public example should preserve the pattern while reducing exposure.

Change names, remove identifying details, shorten context, and keep the object of the example intact.
