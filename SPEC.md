# SPEC

rat-engine converts messy input into a usable artifact.

It works by reading the field, preserving signal, reducing distortion, and choosing one concrete move.

## field

A field is the full working context around an input.

Read for:

- object
- pressure
- claim
- evidence
- setup
- interpretation
- speculation
- distortion
- action

## object

The object is the central thing being handled.

Keep the object central through the whole pass. Keep tone, reaction, performance, and surrounding noise secondary.

## pressure

Pressure is the force acting on the field.

Pressure may come from urgency, ambiguity, emotion, conflict, stakes, missing context, or competing interpretations.

Name the pressure when it changes the needed response.

## signal

Signal is information that changes the shape of the answer.

Preserve signal. Compress around it.

Useful context stays. Decorative context goes.

## distortion

Distortion is anything that makes the field harder to see.

Common distortions:

- vague language
- unsupported certainty
- collapsed distinctions
- ornamental phrasing
- false equivalence
- emotional overreach
- missing evidence
- frame control
- premature synthesis

Reduce distortion before building.

## process

1. Hold the object central.
2. Name the field.
3. Separate claim, evidence, setup, interpretation, and speculation.
4. Preserve signal and useful context.
5. Reduce distortion.
6. Choose one concrete move.
7. Return an artifact.

## moves

Use one primary move per pass.

- MAP shows the structure.
- CUT removes distortion.
- BUILD makes the needed object.
- TEST pressure-checks the claim.
- REFUSE rejects a broken frame.
- QUERY asks for the missing lever.
- SYNTHESIZE joins parts without blurring them.

## artifact

An artifact is the concrete output of the pass.

Examples:

- a map
- a distinction
- a compressed rewrite
- a decision frame
- a test case
- a refusal
- a question
- a draft
- a synthesis

The artifact should be usable outside the moment that produced it.

## checks

Before final output, check:

- Is the object still central?
- Are claim and evidence separated?
- Is useful context preserved?
- Has distortion been reduced?
- Is the metaphor functional?
- Is uncertainty stated cleanly?
- Did the pass return an artifact?

## standard

Output should be clear, compact, usable, and alive.

It should hold shape under rereading.
